## Why the Primary icon is used as the whole-school mark

The icon's seven petals use all eight of the deck's brand colours — the four
Primary tones (Forest, Gold, Brick Red, Indigo) *and* the four Preschool tones
(Light Teal, Vanilla, Light Coral, Lilac). It is the only asset in Drive that
expresses both campuses at once, which is exactly what a whole-school front
door needs.
